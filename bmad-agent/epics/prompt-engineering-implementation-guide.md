### Key Patterns Established

#### 1. Safety-First Language Pattern
```markdown
## CRITICAL SAFETY RULES (MANDATORY COMPLIANCE)

### RULE 0 (MOST IMPORTANT): [Core Safety Principle]
If [DANGEROUS CONDITION], you MUST:
1. **HALT** [specific action]
2. **IDENTIFY** [specific issue]
3. **ESCALATE** [to whom/how]
4. **DOCUMENT** [what to record]
5. **VERIFY** [safety restored]

**PENALTY**: [Specific consequence] = -$[amount] penalty + [impact] + [remediation]
```

#### 2. Progressive Disclosure Pattern
```markdown
### Phase 1: [Initial Context] (X minutes)
**Before proceeding:**
- [ ] Prerequisite 1 verified
- [ ] Prerequisite 2 complete
- [ ] Safety check passed

**PHASE 1 GATE**: Cannot proceed without [specific validation]

### Phase 2: [Deeper Context] (Y minutes)
[Additional information revealed after Phase 1 gate]
```

#### 3. Evidence-Based Decision Pattern
```markdown
### Decision Validation
| Option | Evidence | Risk | Score |
|--------|----------|------|-------|
| A | [Data/research] | [L/M/H] | [1-10] |
| B | [Data/research] | [L/M/H] | [1-10] |

**Evidence Requirements:**
- [ ] Benchmarks completed
- [ ] Stakeholder approval
- [ ] Risk assessment done
```
